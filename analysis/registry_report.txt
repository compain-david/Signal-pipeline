PLANCHER DE RESOLUTION
--------------------------------------------------------------------------
  p ne peut pas descendre sous max(0.5**plis, 1/(apparies+1)), ou
  apparies compte les melanges tombes sur le MEME nombre de plis que
  la serie reelle.
  Le declencheur du repli, exactement : sous 20 apparies, le p est
  calcule sur TOUS les melanges exploitables, pas sur les apparies.
  Ce n est donc pas la seule ligne a zero apparie qui bascule - toute
  ligne sous le seuil bascule, y compris avec 14, 12 ou 11 apparies
  imprimes sur la meme ligne. La colonne 'base du p' dit laquelle,
  parce que sans elle un lecteur attribue le p aux apparies affiches a
  cote, et se trompe de plusieurs centaines de tirages.
  Le PLANCHER, lui, ne bascule jamais : il compte les melanges
  REELLEMENT apparies, pas les 250 lances ni les exploitables du repli.
  Annoncer 1/251 = 0.0040 serait vendre une resolution qu aucune hypothese
  n a atteinte ici. Zero apparie donne donc un plancher de 1.0000 : le
  design n avait aucune resolution, et le p a cote n est qu une
  description.
  id    cible       plis  apparies  plancher         p base du p     barre
  H03   eth_btc        5        14    0.0667    0.2162 tous(221)     0.0050
  H04   eth_btc        9         0    1.0000    0.6937 tous(221)     0.0050
  Avec 4 plis le plancher vaut deja 0.0625 : un walk-forward PARFAIT a

  sortent SOUS_RESOLU : ils n ont pas echoue, ils ne pouvaient pas
  conclure. Les lire comme des quasi-succes serait exactement l erreur
  que ce module combat.

REGLE D ADOPTION
--------------------------------------------------------------------------
  Un signal est ADOPTE seulement si TOUT est vrai :
   1. >= 4 plis de walk-forward
   2. direction HORS ECHANTILLON (majorite des plis de test) egale a la
      direction ENREGISTREE avant la mesure
   3. accord >= max(seuil de l hypothese, 70%)
   4. ecart >= 15 pts contre son PROPRE melange, apparie en plis
   5. p de permutation <= barre corrigee. Sous 20 melanges apparies le
      p est calcule sur tous les melanges exploitables et ne peut plus
      rien conclure : le verdict devient SOUS_RESOLU (colonne
      'base du p').
   6. PREENREGISTREE : >= 270 jours de donnees arrivees APRES elle
  Les criteres 2 a 5 sont tous mesures hors echantillon ou contre une
  nulle. Aucun critere in-sample n entre dans la decision : la colonne
  in-sample du tableau MESURES est informative et rien d autre.
  Le critere 4 est neutralise - il ne peut pas rejeter - quand la nulle
  n est pas appariee, parce que rejeter sur une nulle incomparable
  serait commettre l erreur que ce module audite.
  Le critere 3 est un seuil, pas une preuve : la section CONTRE QUOI
  LIRE UN ACCORD WALK-FORWARD montre qu un predicteur degenere le
  franchit dans ce design. Passer le critere 3 n est donc jamais un
  resultat en soi, ce sont les criteres 2, 4 et 5 qui portent la charge.
  La regle 6 plafonne tout resultat post-hoc a CANDIDAT. Aucune analyse
  faite aujourd hui ne peut donc promouvoir quoi que ce soit
  aujourd hui. C est cher, et c est le seul garde-fou qui tienne.

  Elle demande si le niveau ETH/BTC predit le niveau ETH/BTC, sur

  Accord du controle : 100% sur 5 plis. Aucune hypothese de ce
  groupe ne fait mieux ; 1 l egalent (H01), aucune sur autant de
  plis (aucune). Un predicteur degenere tient donc le haut du tableau.
  C est l inference que ce run publie, et elle va contre l intuition
  qu un accord de plis eleve vaut preuve :
   - la reference implicite d un accord walk-forward est 50%, deux
     directions coincidant a pile ou face. C est ce que dit le
     docstring de walkforward.py, et ce run montre que la reference
     est fausse dans ce design : un predicteur degenere y atteint
     100% sur 5 plis.

     tient dans UNE SEULE tendance baissiere ETH/BTC. Une direction
     de gradient qui ne change pas parce que le regime ne change
     pas se reproduit d un pli au suivant sans qu aucune
     information ne soit en jeu. L accord mesure alors la
     persistance du regime, pas le contenu du signal.
   - donc un accord doit se lire CONTRE LE CONTROLE, pas contre
     50%. Aucun signal de ce groupe ne depasse H03, et le depasser
     serait la seule facon de montrer qu il apporte autre chose que
